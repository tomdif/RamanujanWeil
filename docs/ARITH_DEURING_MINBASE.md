## 1. Integrality (`coeffs`)

If `E` commutes with `Ω`, `ℤ[Ω] ↪ End` (`a + bΩ = 0 ⇒ a = b = 0`) and `E^m = a + bΩ`, then with
`τ = Tr Ω`, `σ = Tr E`:

```
a² − b² deg Ω − mσa + m² deg E = 0,      2ab + b²τ − mσb = 0.
```

Proof: `m²(E² − σE + deg E) = 0` (Cayley–Hamilton, `G8.postcompOf_sq`), expand `(mE)² = (a + bΩ)²`,
reduce with `Ω² = τΩ − deg Ω`, compare coefficients. The algebra (`coeff_identity`) is done in the
commutative subring of Stacks' `postcompSubring A` generated by `Ω` and `E`, as in
`G8.exists_zpow_eq_of_comm`.

## 2. A monogenic generator (`exists_minimalOrder_gen`)

Call `n` admissible if `π = c + nω` for some `c ∈ ℤ` and some `ω ∈ End_π(A)`.

* **Bound.** `coeffs` with `(Ω, E) = (π, ω)`, `(m, a, b) = (n, −c, 1)` gives `nσ = t − 2c` and
  `n² deg ω = c² − tc + q`, so `n²(σ² − 4 deg ω) = t² − 4q`. Hence `n² ∣ t² − 4q ≠ 0`.
* Let `N` be the largest admissible `n` (`Nat.findGreatest`), `π = c + Nω`.
* **`End_π(A) = ℤ[ω]`.** Take `e` commuting with `ω`. By G8, `m e ∈ ℤ[π] ⊆ ℤ[ω]` for some
  `m ≠ 0`. Use strong induction on `|m|`. Take a prime `ℓ ∣ m` with `ℓ e' = a + bω`, `e' = (m/ℓ)e`.
  If `ℓ ∣ a, b`, divide (torsion-freeness) and recurse. Otherwise, integrality gives
  `a² ≡ 0 (mod ℓ)` when `ℓ ∣ b`, so `ℓ ∤ b`. With `uℓ + vb = 1`, `ω₁ = v e' + uω` satisfies
  `ω = ℓω₁ − va`, so `π = (c − Nva) + Nℓ·ω₁`: `Nℓ` is admissible, which contradicts maximality.

The prime `p` needs no special treatment, since the argument uses no torsion points. `p ∤ N` follows
from `N² ∣ t² − 4q` and `p ∣ q`, `p ∤ t`.

## 3. The quotient (`exists_minimalOrder_quotient`)

Hypotheses: `π = c + Nω`, `MinimalOrder ω`, `ℤ[ω] ↪ End`, `N` invertible in `k`.

* G5 `cyclicTorsion_of_minimalOrder` **applied to `ω`** gives `Q` generating `A[N²]` over
  `ℤ[ω]/N²` with trivial annihilator. Put `P = NQ` and `Γ = ⟨P⟩ ≅ ℤ/N`.
* `π`-stable: `πP = cP + ω(NP) = cP`.
* For a quotient `q : A → B = A/Γ` (any `Glue Γ`, any descended `π_B`) and `φ ∈ End_π(B)`, put
  `φ̃ = q ≫ φ ≫ s ∈ End_π(A) = ℤ[ω]`, `φ̃ = x + yω`. Then
  * `φ̃(A[N]) ⊆ Γ` (`comp_sMap_mem`). Applied to `P` and `ωP`, with the annihilator of `P` mod `N`,
    this gives `N ∣ y` and then `N ∣ x`;
  * `φ̃(Q) ∈ Γ` (as `q(φ(q Q))·N = φ(q P) = 0`). With `x = Nx₁`, `y = Ny₁`, the annihilator of `Q`
    mod `N²` gives `N ∣ y₁`.
  * So `φ̃ = N(x₁ − cy₂) + N·y₂·π` up to the factor `N` coming from `q ≫ s = [N]`, i.e.
    `φ̃ = q ≫ (a + bπ_B) ≫ s` with `a = x₁ − cy₂`, `b = y₂`. Cancel `s` (`comp_sMap_injective`) and
    `q` (`Glue.cancel`): `φ = a + bπ_B`.

(Lattice picture: `O = ℤ[ω]`, `ℤ[π] = ℤ + Nℤω`, and `A/⟨1/N⟩` has lattice `N⁻¹ℤ + ℤω ≅ ℤ[π]`.)
